ติดตั้ง Agent บน Windows

คัดลอกคำสั่งด้านล่างไปวางใน PowerShell (Run as Administrator) แล้วกด Enter

สร้าง HEALTH_TOKEN

สุ่ม token ใหม่ได้ที่นี่ แล้วตั้งเป็น secret ใน Cloudflare Dashboard ครั้งเดียว ไม่ต้อง login Wrangler CLI

ยังไม่ได้สร้าง token

ตั้ง secret ครั้งเดียว: Cloudflare Dashboard → Workers & Pages → pc-health-dashboard → Settings → Variables → Secret → HEALTH_TOKEN

Cloudflare Dashboard → Workers & Pages → pc-health-dashboard → Settings → Variables → Secret → HEALTH_TOKEN
เปิด Cloudflare Dashboard

ห้ามแชร์ token หรือ screenshot คำสั่ง install เพราะ token จะฝังอยู่ในคำสั่ง ถ้าเปลี่ยน token ใหม่ต้องรัน installer ใหม่ทุกเครื่องด้วย -Force

  1. ถ้ายังไม่มี token ให้กด สุ่ม Token ใหม่ ตั้งเป็น secret ใน Cloudflare Dashboard แล้วใช้คำสั่งด้านล่างที่มี token ฝังอยู่
  2. เปิด PowerShell แบบ Run as Administrator บนเครื่อง Windows ที่ต้องการตรวจสอบ
  3. วางคำสั่งด้านล่างแล้วกด Enter
  4. ใส่ HEALTH_TOKEN เมื่อระบบถาม ระบบจะสร้าง Windows Service ชื่อ PCHealthAgent และเริ่มส่งทันที
irm https://pc-health-dashboard.apichat-p-1989.workers.dev/agent/bootstrap.ps1 | iex

หากเคยติดตั้งแล้วแต่ยังไม่ขึ้นข้อมูล ให้ใช้คำสั่งติดตั้งใหม่นี้ (จะถาม token อีกครั้ง)

$bootstrap = irm https://pc-health-dashboard.apichat-p-1989.workers.dev/agent/bootstrap.ps1; & ([scriptblock]::Create($bootstrap)) -Force

หรือตรวจสอบการติดตั้ง/ทดสอบส่งข้อมูล 1 ครั้งด้วยคำสั่งนี้

powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\PCHealthAgent\diagnose.ps1"

ถอนการติดตั้ง: ลบ Windows Service, Scheduled Task เก่า และไฟล์ agent ทั้งหมด

$bootstrap = irm https://pc-health-dashboard.apichat-p-1989.workers.dev/agent/bootstrap.ps1; & ([scriptblock]::Create($bootstrap)) -Uninstall -RemoveFiles
  1. เปิด PowerShell แบบ Run as Administrator บนเครื่องที่ต้องการถอนการติดตั้ง
  2. วางคำสั่งข้างบนแล้วกด Enter
  3. ตรวจสอบด้วย Get-Service PCHealthAgent ควรขึ้นว่าไม่พบ service
  4. Refresh dashboard เครื่องจะเปลี่ยนเป็น offline ภายในประมาณ 5 นาที
ดาวน์โหลด bootstrap.ps1 ดาวน์โหลดทั้งโปรเจกต์ (ZIP)

คำสั่งจะโหลดไฟล์ agent ไปยัง %LOCALAPPDATA%\PCHealthAgent สร้าง Windows Service ชื่อ PCHealthAgent ที่ start อัตโนมัติตอน boot และ restart เองถ้า agent ตาย เริ่มส่งข้อมูลทุก 10 วินาที token ที่สร้างในหน้าเว็บจะถูกฝังลงในคำสั่ง install/reinstall หลังกด สุ่ม Token ใหม่ และอยู่ใน browser ของคุณเท่านั้น ไม่ถูกส่งไปเก็บใน Worker อัตโนมัติ
